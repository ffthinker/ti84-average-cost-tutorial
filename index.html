Average Cost Function

PRACTICE   |   LEARN   |   SUCCEED

The Problem

A company has the average cost function, in dollars per computer,

C̄(x) = 0.56x² − 34.39x + 1212.57 + 20,000/x

where x is the number of computers produced.

  1. Find C̄(30).
  2. Find C̄(40).
  3. Find C̄(50).
  4. Graph for 0 < x ≤ 80.
  5. Use the table to locate the minimum average cost and the number of computers that produces it.
